# Unnati Global Trade

Next.js + TypeScript + Tailwind CSS starter website based on the supplied project specification.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production

```bash
npm run build
npm start
```

## Notes
- Contact email/phone are intentionally placeholders.
- Product specifications are intentionally not invented.
- Replace placeholder visual blocks with licensed product/technology imagery.
- Add real form backend/API before accepting production inquiries.
